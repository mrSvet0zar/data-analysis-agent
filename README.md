# 🤖 Data Analysis Agent

An **autonomous AI agent** that analyzes any CSV file on its own. You upload a
dataset and a request; the agent — powered by Claude's native tool-use — decides
which tools to call, executes them, iterates, and produces an interactive report
with visualizations. Every step streams live to the browser over WebSockets.

## What makes it an "agent"?

It's not a fixed pipeline. The backend runs a **tool-use loop**: Claude receives
the request plus a toolbox, and *chooses* what to do next based on what it has
learned so far.

```
user request + CSV
      │
      ▼
┌───────────────────────────────────────────┐
│  Agent loop (backend/app/agent.py)         │
│                                            │
│   Claude ──► "call read_csv"               │
│     ▲              │                       │
│     │              ▼                       │
│   tool result ◄── execute tool             │
│     │              │                       │
│     └──── repeats until Claude says done ──┘
│                                            │
└───────────────────────────────────────────┘
      │  (each step streamed via WebSocket)
      ▼
   report + charts
```

### The 6 tools the agent can call

| Tool | What it does |
|------|--------------|
| `read_csv` | Inspect structure: shape, dtypes, missing values, preview |
| `describe_statistics` | mean/std/quartiles + skewness & kurtosis |
| `detect_outliers` | IQR or Z-score outlier detection per column |
| `correlation_analysis` | Pearson matrix + strongest pairs |
| `create_visualization` | Interactive Plotly chart (histogram/scatter/heatmap/box/timeseries) |
| `generate_report` | Compile findings into a markdown report |

## Quickstart

### 1. Backend

```bash
cd backend
python -m venv venv
# Windows: venv\Scripts\activate   |   macOS/Linux: source venv/bin/activate
venv/Scripts/pip install -r requirements.txt

cp .env.example .env         # then edit .env and paste your ANTHROPIC_API_KEY
venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
```

Backend runs at `http://localhost:8000` (`/health` to check, `/docs` for the API).

### 2. Frontend

```bash
cd frontend
npm install
cp .env.example .env         # VITE_API_URL defaults to http://localhost:8000
npm run dev
```

Open `http://localhost:5173`, drop in `backend/sample_data/sales.csv`, and watch
the agent work.

## Configuration (`backend/.env`)

| Variable | Default | Notes |
|----------|---------|-------|
| `ANTHROPIC_API_KEY` | — | **required** |
| `ANTHROPIC_MODEL` | `claude-sonnet-5` | any current Claude model id |
| `MAX_ITERATIONS` | `12` | safety cap on agent loop turns |
| `MAX_FILE_SIZE` | `52428800` | 50 MB upload limit |
| `CORS_ORIGINS` | localhost:5173 | comma-separated |

## Notes & design decisions

- **Real-time progress actually works.** The agent takes an `on_step` callback
  invoked after every step; the WebSocket streams those as they happen (rather
  than only at the end).
- **Async all the way.** `AsyncAnthropic` + `asyncio.to_thread` for pandas work
  keep the event loop free so streaming stays smooth.
- **The model never sees file paths.** `file_path` is injected server-side, so
  the agent can't be steered into reading arbitrary files.
- **Charts travel as Plotly JSON**, rendered natively by `react-plotly.js`.
